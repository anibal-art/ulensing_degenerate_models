# Validation utilities

Numerical and statistical validation experiments used to justify choices in the hidden-parallax pipeline.

- `detectability/`: Rubin pre-fit detectability audits.
- `lrt/`: LRT Monte Carlo and FAST-versus-DE validation.
- `optimizer/`: optimizer and parameter-bound sensitivity tests.

These are validation tools, not ordinary catalogue-production entry points. See the repository-level `README.md`.
